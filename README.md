# TecnoMovil Data — EA2

Proyecto de consola en Java para procesar registros simulados de transporte urbano usando Streams, lambdas, funciones de transformación y colecciones no modificables.

## Requisitos
- JDK 17 o superior
- Sin frameworks ni dependencias externas

## Ejecución (desde la raíz)
```bash
javac -encoding UTF-8 -d out src/main/java/com/tecnomovil/Main.java
java -cp out com.tecnomovil.Main
```

## Análisis implementados
1. Afluencia por estación.
2. Entradas por hora.
3. Rutas más utilizadas.
4. Patrones de viaje por usuario.
5. Tiempo promedio estimado entre estaciones diferentes.
6. Detección de rutas críticas con umbral simulado.
